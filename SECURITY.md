# Security

Integracja może uzbrajać i rozbrajać system alarmowy.

## Zalecenia wdrożeniowe

- używaj szyfrowania integracji SATEL;
- używaj dedykowanego użytkownika / kodu dla Home Assistanta;
- ogranicz dostęp do portu ETHM-1 firewall-em do adresu Home Assistanta;
- nie wystawiaj portu integracyjnego do Internetu;
- nie publikuj logów zawierających kody, klucze integracji ani dane uwierzytelniające.

## Zgłaszanie problemów bezpieczeństwa

Nie publikuj sekretów w publicznym issue. Jeśli repozytorium będzie publiczne, skonfiguruj GitHub Private Vulnerability Reporting lub wskaż prywatny kanał kontaktu w tym pliku.
